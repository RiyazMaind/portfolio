# Riyaz Maind - Data Science & Analytics Portfolio

A modern, responsive portfolio website showcasing data science projects, machine learning models, and analytics work. Built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS**.

## 🌟 Features

- **Modern Design**: Sleek dark theme with blue accents, smooth animations
- **Fully Responsive**: Mobile-first design, works on all devices
- **SEO Optimized**: Structured data JSON-LD, sitemap, robots.txt, optimized metadata
- **Contact Form**: Email integration using Resend API
- **Social Media Links**: LinkedIn, GitHub, X (Twitter) profiles
- **Experience Timeline**: Professional roles and responsibilities
- **Skills Showcase**: Organized by category (Languages, ML, DL, Tools)
- **Project Portfolio**: Featured data science and ML projects

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or Bun
- npm/yarn/pnpm package manager

### Installation

1. Clone the repository

   ```bash
   git clone https://github.com/riyazmaind/portfolio.git
   cd portfolio
   ```

2. Install dependencies

   ```bash
   npm install
   ```

3. Configure environment variables

   ```bash
   cp .env.example .env.local
   ```

   Edit `.env.local` with your Resend credentials

4. Run the development server
   ```bash
   npm run dev
   ```
